# 全连接网络总结

## 一句话总结
用 3 个字符的上下文 + 可学习 embedding（46×10）替代"1 字符上下文 + one-hot"，通过两层全连接（tanh 激活）预测下一个字符；本机训练后 NLL 约 2.17（低于 Bigram 的 2.49），生成的名字明显更接近真实名字（如 JEAN.、MARIANE.）。

## 核心概念
- **滑动窗口 / 上下文（block_size=3）**：样本数由"每个字符产生一个标签"决定，与窗口宽度无关（仍为 226325）；窗口只决定每个样本看多远。
- **embedding（C[X]）**：与 one-hot @ W 同一机制（按编号查表取行），但把 46 位稀疏向量换成 10 维稠密可学习向量；相似上下文的字符会被梯度推向相近位置（可计算余弦相似度验证）。
- **网络结构**：拼接(30) → W1(30,200) → tanh → W2(200,46) → logits → CrossEntropyLoss（= softmax + NLL）。参数 15906。
- **非线性必要性**：没有 tanh，(x@W1)@W2 = x@(W1@W2)，两层塌缩成一层线性变换，表达能力退化为"直线"。
- **学习率扫描**：`10**linspace(-3,0,1000)`，曲线呈 U 形；低谷（lr≈0.2~0.3）为最优区间；本课选 lr=0.2。
- **mini-batch 训练**：batch_size=256，train/val/test = 80/10/10；50 epoch 后 lr 衰减 ×0.1。
- **低维 embedding 的代价**：2 维嵌入 loss 高于 10 维（~2.39 vs ~2.17），因为 2 维空间装不下全部字符差异；维度是表达能力。

## 代码范式
```python
# 前向（手写，等价于 nn.Sequential 两层）
emb = C[x]                                    # (N,3,10) 查表
h = torch.tanh(emb.view(-1, block_size*embed_dim) @ W1 + b1)
logits = h @ W2 + b2
loss = F.cross_entropy(logits, y)

# 训练（每 epoch 平均，.item() 取值）
for p in parameters: p.grad = None
loss.backward()
for p in parameters:
    p.data -= cur_lr * p.grad

# 生成：context 滑窗 + softmax + multinomial
```

## 踩坑记录
- **学习率扫描后忘重新初始化参数**：扫描的 1000 步已经把模型"预训练"过，接着训练会让 epoch 0 起点过低（2.17 而非 ~5.27），曲线失真；训练前必须重跑参数初始化 cell。
- loss 累加要用 `.item()`（Day1 的老坑）。
- val/test 的 DataLoader 要 `shuffle=False`。
- `random_split` 传整数长度最稳（测试集用 `n - train - val` 避免取整误差）。
- `emb.view(-1, block_size*embed_dim)` 不要写死 30，改超参才不会不同步。
- 独热是"展开"不是"压缩"：46 位 vs 二进制 6 位，但它抹掉了整数的大小顺序。
