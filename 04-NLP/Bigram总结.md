# Bigram 总结

## 一句话总结
Bigram 是"只看前一个字符"的字符级语言模型：统计相邻字符对出现次数，归一化成条件概率表，就能按概率采样生成名字。它的上限受限于"固定上下文长度为 1"，平均 NLL ≈ 2.49。

## 核心概念
- **token**：模型的输入单元，这里是一个字符；现代模型（GPT 等）里是更复杂的 token。
- **"." 特殊字符**：标记名字开头/结尾；同时充当"隔板"，保证逐词计数时不会产生跨词假配对。
- **共现矩阵 N（46×46）**：行 = 当前字符，列 = 下一个字符，格子 = 出现次数。
- **条件概率**：P[i, j] = P(下一个字符 = j | 当前字符 = i)；行归一化后每行和为 1。
- **广播与 keepdims**：`(46,46) / (46,1)` 是"每行除以行和"（正确）；`(46,46) / (46,)` 向量对齐列轴，方阵时静默算错。
- **采样 vs 贪心**：`torch.multinomial` 按概率随机抽（有多样性）；`argmax` 永远选最大（名字全一样）。
- **负对数似然 NLL**：`-log(概率)` 的平均；越小越好。参照物：完美模型 = 0，瞎猜 = log(46) ≈ 3.83，计数版天花板 = 2.49。
- **独热编码**：1-of-K 向量，抹掉整数自带的大小/顺序；`xenc @ W` = 取出 W 的第 i 行（查表）。
- **softmax**：分数 → 概率；`F.softmax` 数值稳定，优于手动 exp/sum。
- **神经网络版与计数版等价**：线性层 + softmax + 全量 NLL 的全局最优，正是计数版的概率表（`W[i,j] = log P[j|i]`）。

## 代码范式
```python
# 计数版生成
def gen_name():
    out, ix = [], 0
    while True:
        p = P[ix]
        ix = torch.multinomial(p, 1, replacement=True).item()
        out.append(itos[ix])
        if ix == 0: break
    return ''.join(out)

# 神经网络版训练（关键四步）
logits = xenc @ W
probs = F.softmax(logits, dim=1)
loss = -probs[torch.arange(len(xs)), ys].log().mean()
W.grad = None; loss.backward(); W.data -= 50 * W.grad
```

## 踩坑记录
- **滑动窗口配对**：`zip(chs, chs[1:])` 要完整配对；不要把多个名字拼接成一个长串再计数（会制造跨词边界的假 bigram）。
- **f-string 忘写 f**：`"总共有{N.sum()...}"` 会把花括号当普通文字打印。
- **`.item()` vs `.items()`**：张量取数值用 `.item()`；`.items()` 是字典的方法。
- **打印全 0**：创建 / 填充 / 打印要放在同一个 cell 连着跑；重跑 `torch.zeros` 后忘了重跑填充循环就会出现"总和 226325 但矩阵全 0"。
- **keepdims 丢了**：`(46,)` 对齐列轴，方阵不报错但结果语义全错——比报错更危险。
- **整数除法截断**：算概率前先 `.float()`。

- 为什么 100 步后 loss 停在 2.55 而不是 2.49？（未完全收敛；`W=log P` 才是精确最优）
