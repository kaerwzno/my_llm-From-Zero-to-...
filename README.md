# 我的大语言模型学习历程

## 1.前置知识

微积分和线性代数

线性代数推荐MIT和3blue1brown的



## 2.相关知识

速刷一遍机器学习和深度学习的相关知识

推荐吴恩达的机器学习，可以开倍速快速刷完course1和course2，不用管lab

深度学习这边可以看一点李宏毅的课，不需要完全看



## 3.开始动手

- 从卡帕西《神经网络：从零到英雄》第一节课，直接上手编程。

如果前期没有pytorch基础，建议刷一下pytorch官网的快速入门

[[PyTorch 深度学习：60分钟快速入门 — PyTorch Tutorials 2.14.0+cu130 文档 - PyTorch 文档](https://docs.pytorch.ac.cn/tutorials/beginner/deep_learning_60min_blitz.html)]

- 然后卡帕西到bigram那节，如果觉得有点跳跃，可以配合这个教程食用

[深度学习课程 🚀 — Deep Learning Course](https://simonthomine.github.io/CoursDeepLearning/zh/README.html)

主包就是这样在各个版本之间来回切换。

这个教程还包含CNN和RNN可以动手实现一下，关于CNN当时主包没有很明白，就去看了李宏毅的视频，就很理解了。同时推荐另一个up主的视频[唐一旦聊AI的个人空间-唐一旦聊AI个人主页-哔哩哔哩视频](https://space.bilibili.com/417265639?spm_id_from=333.788.upinfo.head.click) 

- 然后主包就跟着实现了CNN（小小偏离一下LLM路线....）一开始不用了解太深，有点印象即可。

- 关于残差连接网络可以继续看up主唐一旦的视频，Wavenet简单了解一下即可（主包赶进度，直接跳过了K神的这一段）



## 4.继续补习知识
