# 卷积神经网络（CNN）基础知识

> 核心动机：MLP 处理图像时需要把所有像素连接到全连接层，参数量容易爆炸；CNN 通过**局部连接**和**参数共享**减少参数，并保留图像的空间结构。

---

## 一、卷积核（Kernel / Filter）

![](e0a9b70d-1a1f-4347-ad48-8675062e5815.png)

卷积核是一个小矩阵（如 `3×3`），在图像上滑动，与覆盖区域逐元素相乘后求和，得到特征图中的一个值。卷积核中的数值是可训练的参数，相当于网络中的权重。

### 填充 Padding

卷积核无法完整覆盖边缘时，边缘像素参与计算的次数较少。Padding 会在图像四周补值（常见是补 `0`），使边缘信息得到更充分的利用，也可以控制输出尺寸。

### 步长 Stride（`s`）

卷积核每次滑动的距离：

- `s=1`：逐格滑动，最常用；
- `s=2`：每次跳一格，输出空间尺寸通常会缩小。

### 输出尺寸公式

输入边长为 `n`，卷积核边长为 `f`，填充为 `p`，步长为 `s`：

$$
\text{out} = \left\lfloor\frac{n + 2p - f}{s}\right\rfloor + 1
$$

当 `s=1` 且希望输出尺寸不变时，通常取 `p=(f-1)/2`：例如 `f=3` 时取 `p=1`。

## 二、多通道卷积

![](88ba264b-dc28-466d-bef2-d16261d6c9e4.png)

图片通常可以表示为 `高 × 宽 × 通道`：灰度图有 1 个通道，RGB 图有 3 个通道。在 PyTorch 中，图像批次通常使用 `(B, C, H, W)` 的顺序。

两条规则：

| 规则 | 说明 |
|---|---|
| 卷积核深度 = 输入通道数 | 每个输入通道各自计算，最后将结果相加并加上偏置 |
| 输出通道数 = 卷积核个数 | 每个卷积核提取一种特征，因此产生一个输出通道 |

即：`输入 (H, W, C_in)` + `C_out` 个卷积核 → `输出 (H', W', C_out)`。

对应 PyTorch：

```python
nn.Conv2d(in_channels, out_channels, kernel_size)
#         输入通道数   输出通道数（卷积核个数）
```

## 三、池化层（Pooling）

池化层通常不含可学习参数，主要压缩特征图的空间尺寸：

| 类型 | 操作 | 特点 |
|---|---|---|
| MaxPooling（常用） | 取邻域最大值 | 保留最强特征，对局部噪声较稳健 |
| AveragePooling | 取邻域平均值 | 平滑特征，保留整体背景信息 |

池化可以减少计算量，并增强模型对小范围平移、形变的鲁棒性。

```python
nn.MaxPool2d(kernel_size=2, stride=2)
```

使用 `2×2` 窗口、步长为 `2` 时，空间高度和宽度通常各缩小一半。

---

## 四、为什么 CNN 比 MLP 更适合图像

1. **局部连接**：每个输出只依赖输入的局部区域，不必连接整张图片。
2. **参数共享**：同一个卷积核在整张图上复用，检测同一种特征；例如 `3×3` 卷积核的核心权重规模与图像大小无关。
3. **保留空间结构**：卷积处理相邻像素之间的关系，而 MLP 展平后会丢失显式的空间邻接关系。
4. **一定的平移鲁棒性**：卷积核可以在不同位置检测相同特征，池化也能减弱小范围位置变化的影响。

---

## 五、CNN 的典型结构

**核心规律**：网络加深时，空间尺寸通常逐渐减小，通道数通常逐渐增加。

```text
浅层（边缘）──→ 中层（形状、纹理）──→ 深层（物体语义）
通道少、图大       通道增加、图变小        特征更抽象
```

| 层 | 作用 | 是否有可学习参数 |
|---|---|---|
| `nn.Conv2d` | 提取特征、改变通道数 | 有 |
| `ReLU` | 引入非线性 | 无 |
| `nn.MaxPool2d` | 压缩空间尺寸 | 无 |
| `nn.Linear` | 根据特征进行分类 | 有 |

卷积特征经过展平后，通常接全连接层，最后输出类别数个分数。

> `BatchNorm`、`Dropout` 等正则化或稳定训练的方法同样可以用于 CNN。

---

## 六、感受野（Receptive Field）

感受野是某个输出位置能够“看到”的原始输入区域。一层 `3×3` 卷积只能看到 `3×3` 区域；连续堆叠卷积可以扩大感受野：

```text
第 1 层 3×3：感受野为 3×3
第 2 层 3×3：感受野为 5×5
第 3 层 3×3：感受野为 7×7
```

逐层计算时：

$$
RF_{out} = RF_{in} + (k - 1) \times j
$$

- `RF_in`：输入的感受野；
- `k`：当前卷积核尺寸；
- `j`：前面各层步长的累计乘积。

输入图像越大，通常越需要更大的感受野来捕捉远距离的特征关系。

---

## 七、特征图可视化：各层在学什么

| 深度 | 常见特征 |
|---|---|
| 浅层 | 边缘、颜色、基础纹理等局部信息 |
| 中层 | 形状、图案等复合特征 |
| 深层 | 物体部件、整体布局等语义信息 |

这些是常见的经验性理解，具体特征仍取决于数据集、网络结构和训练结果。

## 八、CNN 实战：MNIST 手写数字分类

本节对应 `卷积神经网络2.ipynb`。任务是输入 `28×28` 的灰度手写数字图片，输出 `0~9` 共 10 个类别中的一个。

### 8.1 导入模块与加载数据

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import DataLoader, random_split
from torchvision import datasets
import torchvision.transforms as transforms
import matplotlib.pyplot as plt

# ToTensor() 将图片转换为张量，并把像素值缩放到 [0, 1]
dataset = datasets.MNIST(
    root='./mnist',
    train=True,
    download=True,
    transform=transforms.ToTensor()
)

# 从官方训练集划出训练集和验证集
train_set, val_set = random_split(dataset, [50000, 10000])

test_set = datasets.MNIST(
    root='./mnist',
    train=False,
    download=True,
    transform=transforms.ToTensor()
)

# 一个 batch 是一次送入模型的一小批样本
train_loader = DataLoader(train_set, batch_size=500, shuffle=True)
val_loader = DataLoader(val_set, batch_size=500, shuffle=False)
test_loader = DataLoader(test_set, batch_size=500, shuffle=False)
```

如果 `batch_size=500`，一个 batch 的形状通常为：

```text
images: (500, 1, 28, 28)
labels: (500,)
```

这里 `500` 是样本数量，`1` 是灰度通道数，`28×28` 是图像尺寸。训练集有 50,000 张图片，因此每个 epoch 有 `50000/500=100` 个 batch。

- **batch**：一次处理的一批样本；
- **iteration/step**：处理一个 batch 并更新一次参数；
- **epoch**：完整遍历一次训练集。

### 8.2 定义 CNN 模型

```python
class CNN(nn.Module):
    def __init__(self):
        super().__init__()

        # 输入 (B,1,28,28)，无 padding，28-5+1=24
        self.conv1 = nn.Conv2d(1, 20, kernel_size=5)
        # (B,20,24,24) -> (B,20,12,12)
        self.pool1 = nn.MaxPool2d(kernel_size=2, stride=2)

        # 12-5+1=8
        self.conv2 = nn.Conv2d(20, 40, kernel_size=5)
        # (B,40,8,8) -> (B,40,4,4)
        self.pool2 = nn.MaxPool2d(kernel_size=2, stride=2)

        # 展平后：40 * 4 * 4 = 640 个特征
        self.fc1 = nn.Linear(640, 120)
        self.fc2 = nn.Linear(120, 10)  # 10 个类别：数字 0~9

    def forward(self, x):
        # x: (B,1,28,28)
        x = F.relu(self.conv1(x))  # (B,20,24,24)
        x = self.pool1(x)          # (B,20,12,12)

        x = F.relu(self.conv2(x))  # (B,40,8,8)
        x = self.pool2(x)          # (B,40,4,4)

        # Linear 要求输入形状为 (B, 特征数)。
        # view(B,-1) 保留 batch 维，把每张图片的特征展平：
        # (B,40,4,4) -> (B,640)
        B = x.shape[0]
        x = x.view(B, -1)

        x = F.relu(self.fc1(x))    # (B,640) -> (B,120)
        x = self.fc2(x)             # (B,120) -> (B,10)

        # 最后一层不加 ReLU/Softmax，返回 logits。
        # CrossEntropyLoss 内部会进行数值稳定的 LogSoftmax 和 NLLLoss。
        return x

model = CNN()
```

#### `x.view(B, -1)` 的含义

`x` 的形状是 `(B, 40, 4, 4)`：

- `B`：一个 batch 中有多少张图片；
- `40`：通道数，也就是特征图数量；
- `4×4`：每张特征图的空间尺寸。

`view(B, -1)` 的结果是 `(B, 640)`。`-1` 不是“一个元素”，而是让 PyTorch 根据总元素数自动计算该维度：`40×4×4=640`。

要区分：

```text
shape = (500,)：一个一维向量，包含 500 个元素
shape = (1, 500)：二维张量，1 行 500 列
```

因此 `labels.shape=(500,)` 表示一个包含 500 个标签的一维向量，不是只有一个元素。

#### 为什么最后一层不加激活函数？

`fc2` 输出 10 个 logits，即 10 个类别的原始分数。训练时：

```python
criterion = nn.CrossEntropyLoss()
loss = criterion(preds, labels)
```

`CrossEntropyLoss` 已经包含了适合分类的 `LogSoftmax` 和负对数似然损失，因此模型最后不需要手动加 `Softmax`。预测类别直接取分数最大的下标即可：

```python
predicted = preds.argmax(dim=1)
```

### 8.3 训练与验证

```python
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001,
    weight_decay=0.001
)

epochs = 10
train_losses = []
val_losses = []

for epoch in range(epochs):
    # train() 会启用 Dropout 等层的训练行为；没有这些层时也建议保留。
    model.train()
    loss_train = 0.0

    for images, labels in train_loader:
        preds = model(images)
        loss = criterion(preds, labels)

        # 一次参数更新的标准顺序
        optimizer.zero_grad()  # 清除上一次累积的梯度
        loss.backward()        # 根据 loss 计算梯度
        optimizer.step()       # 用梯度更新参数

        loss_train += loss.item()

    # 验证阶段只评估，不计算梯度，也不更新参数
    model.eval()
    loss_val = 0.0

    # no_grad() 放在 for 循环外即可覆盖整个验证循环
    with torch.no_grad():
        for images, labels in val_loader:
            preds = model(images)
            loss = criterion(preds, labels)
            loss_val += loss.item()

    # 用平均损失而不是总损失，避免受 batch 数量影响
    avg_train_loss = loss_train / len(train_loader)
    avg_val_loss = loss_val / len(val_loader)

    train_losses.append(avg_train_loss)
    val_losses.append(avg_val_loss)

    print(
        f'Epoch {epoch + 1}: '
        f'train_loss={avg_train_loss:.4f}, '
        f'val_loss={avg_val_loss:.4f}'
    )
```

### 8.4 绘制训练和验证损失曲线

必须先用列表保存每个 epoch 的平均损失，训练结束后再绘图：

```python
plt.figure(figsize=(7, 4))
plt.plot(range(1, epochs + 1), train_losses, label='Train Loss')
plt.plot(range(1, epochs + 1), val_losses, label='Validation Loss')
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.title('Training and Validation Loss')
plt.legend()
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()
```

曲线的常见判断方式：

- 训练损失和验证损失都下降：模型还在学习；
- 训练损失下降、验证损失持续上升：可能开始过拟合；
- 两者都较高且下降缓慢：可能欠拟合，或学习率、模型结构不合适。

单个 epoch 的验证损失轻微上升不一定是过拟合，要看后续是否持续上升。实践中可以保存验证损失最低的模型：

```python
best_val_loss = float('inf')

# 在每个 epoch 得到 avg_val_loss 后执行
if avg_val_loss < best_val_loss:
    best_val_loss = avg_val_loss
    torch.save(model.state_dict(), 'best_cnn.pth')
```

### 8.5 测试集评估

```python
model.eval()
correct = 0
total = 0

with torch.no_grad():
    for images, labels in test_loader:
        preds = model(images)              # (B,10)
        predicted = preds.argmax(dim=1)    # (B,)

        # labels.shape=(B)，size(0) 是第 0 维的长度，即当前 batch 的样本数
        total += labels.size(0)
        correct += (predicted == labels).sum().item()

print(f'测试集准确率：{correct / total * 100:.2f}%')
```

`labels` 是一个一维向量，但“一维”表示只有一个轴，不表示只有一个元素：

```python
labels.shape == (500,)
labels.size(0) == 500
```

`(predicted == labels)` 会得到一组布尔值，`.sum()` 统计其中有多少个 `True`，即当前 batch 预测正确的数量。最终：

```text
准确率 = 预测正确的样本数 / 总样本数
```

本次实验测试准确率约为 `98.69%`。

## 九、常见问题与踩坑记录

### 1. `nn.Linear(-1, 120)` 报错

`-1` 可以用于 `view`、`reshape` 等改变张量形状的操作，让框架自动推断维度；但 `nn.Linear(in_features, out_features)` 的 `in_features` 必须是确定的整数。

本例中：

```text
(B,1,28,28)
→ conv1: (B,20,24,24)
→ pool1: (B,20,12,12)
→ conv2: (B,40,8,8)
→ pool2: (B,40,4,4)
→ 展平: (B,40×4×4) = (B,640)
```

因此必须写：

```python
self.fc1 = nn.Linear(640, 120)
```

### 2. `import torch` 出现 `partially initialized module`

例如：

```text
AttributeError: partially initialized module 'torch' has no attribute 'distributed'
```

这通常发生在 PyTorch 没有完整初始化时，可能原因包括：Notebook 内核残留了失败的导入、项目中存在 `torch.py`/`torch` 文件夹、VS Code 使用了错误的 Python 环境，或 PyTorch 安装损坏。

排查顺序：

1. 重启 Notebook Kernel；
2. 检查 `sys.executable`，确认使用的是目标 conda 环境；
3. 检查当前目录是否有 `torch.py` 或 `torch` 文件夹；
4. 在目标环境中执行 `python -c "import torch; print(torch.__file__)"`；
5. 必要时重新安装匹配版本的 `torch`、`torchvision`。

### 3. 第一个 epoch 的验证损失比训练损失低

这不一定是错误。训练损失是模型从 epoch 开始到结束、逐批训练过程中的平均值；验证损失是在该 epoch 训练完成后才计算的，此时模型已经学到了一些东西。两者不是在同一时刻测量的。

### 4. `labels.size(0)` 的含义

若：

```python
labels.shape == (500,)
```

它表示一个一维向量，包含 500 个标签。这里：

- `ndim == 1`：维度数量为 1；
- `size(0) == 500`：第 0 个维度的长度为 500。

不要把“维度数量”和“维度长度”混淆。

### 5. 验证/测试阶段忘记 `eval()` 或 `no_grad()`

推荐写法：

```python
model.eval()
with torch.no_grad():
    preds = model(images)
```

`eval()` 会切换 Dropout、BatchNorm 等层的行为；`no_grad()` 会关闭梯度记录，节省内存和计算。训练阶段不能使用 `no_grad()`，否则无法执行正常的反向传播。

### 6. 训练和测试的设备不一致

如果使用 GPU，模型和数据必须在同一设备：

```python
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = model.to(device)

for images, labels in train_loader:
    images = images.to(device)
    labels = labels.to(device)
```

### 7. 训练循环中忘记清空梯度

PyTorch 默认会累积梯度，因此每个 batch 更新前都要执行：

```python
optimizer.zero_grad()
```

否则当前 batch 的梯度会和之前 batch 的梯度叠加，导致训练结果异常。

## 附：PyTorch API 速查

```python
# 卷积层
nn.Conv2d(
    in_channels,
    out_channels,
    kernel_size,
    stride=1,
    padding=0
)

# 池化层：stride 默认通常等于 kernel_size
nn.MaxPool2d(kernel_size, stride=None)

# 常用激活函数
F.relu(x)

# 展平卷积输出；保留 batch 维
x = torch.flatten(x, start_dim=1)
# 等价写法（已知 batch 维 B 时）
x = x.view(B, -1)

# 分类损失：输入 logits，标签为类别下标
nn.CrossEntropyLoss()

# 切换模式
model.train()  # 训练
model.eval()   # 验证/测试

# 关闭梯度记录
with torch.no_grad():
    ...

# 取每个样本分数最大的类别
predicted = logits.argmax(dim=1)
```

### 训练流程速记

```text
取一个 batch
→ 前向传播 model(images)
→ 计算损失 criterion(preds, labels)
→ 清空梯度 zero_grad()
→ 反向传播 loss.backward()
→ 更新参数 optimizer.step()

完整遍历训练集一次 = 1 个 epoch
```
